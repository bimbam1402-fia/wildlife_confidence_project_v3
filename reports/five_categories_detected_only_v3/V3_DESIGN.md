# V3: detected-only revision

Exact V2 selected-event subset with all full-frame fallbacks excluded from all five partitions. No new frame selection, replacement events or camera reassignment. Camera/preparation provenance files remain unchanged V2 records. V3 protocol and selection records identify the new experiment. The initial 20% development camera-share cap is inherited before exclusions; post-exclusion shares are recorded, not claimed to remain capped. All models start from the same ImageNet recipes, with new V3 checkpoints, temperatures and policies. V2 remains unchanged.

Detection success does not establish semantic crop correctness. Excluded frames are no-detection events, not automatically verified empty scenes. Detection recall and unfiltered-stream coverage are outside scope. V3 coverage is conditional on retained detected events. Prior V1/V2 test exposure means this is a revised experiment, not independent confirmation on new cameras.
